# Zone language and video angles (owner answers, 2026-10-07)

## Zone language

Owner: coaches split the zone into four or nine "pockets" (transcribed as "force or nine"; read as four). The S2 grid we tested is 3 heights x 3 sides = nine pockets, crossed with pitch family, so the validated shape already matches the nine-pocket language. Card wording: "high-in", "middle-away" and so on, not "S2".

Open: the four-pocket version (up/down x in/away) has not been tested. It is coarser, so it would likely pass less often on real results. If coaches mostly think in four, either show nine and group them, or run the four-pocket test first. Needs the owner's call on which one coaches use more.

## Video angles available (owner list)

- Low home: behind the plate, shows pitcher, catcher and batter. Closest to the catcher's view. Shows where the pitch crosses the plate against the zone.
- Open-side pitcher angle: from the pitcher's open side. Shows release point, arm slot and the pitcher's body.
- Center field (broadcast style): head-on, closest to what the hitter sees. Shows the pitch's flight toward the plate.

## First view on which angle does which job (my reasoning, not tested)

- Recognition clip, cut off after release: center field. It is closest to the hitter's eye line, so the cue he has to read (spin, early path, shape) is what he sees in the box.
- Feedback after the answer: low home. It shows where the pitch ended up in the pockets, which is what the zone-tendency map uses.
- Open-side pitcher: release and arm-slot reading, plus pitcher tells. Useful for the "starter's confusable pairs" block (does the sweeper look like the fastball at release from this arm slot?). Least like the hitter's view.

Whether this ordering helps is untested. It is also a place the pilot can compare: same clips, two angles.

## What still decides feasibility (Gate V)

1. Which of these angles Visalia actually records every game, at what frame rate, and who can export clips.
2. Whether video timestamps can be matched to tracking data (TrackMan) pitch by pitch. If yes, clips can be cut automatically at release and tagged with pitch type and pocket. If no, someone has to cut and label by hand, which will not scale.
3. Whether the org allows using game video outside the club's own systems.
